# Artisanal Food Retail — Website

> Conversion-focused website prototype for artisanal food retail, featuring a category storefront and producer provenance stories.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Artisanal food retail

Conversion-focused website prototype for artisanal food retail, featuring a category storefront and producer provenance stories.

**Highlights**

- Storefront by category: cheeses, sweets, coffees and cured meats
- Producer profiles and provenance stories
- Gift kits and curated hampers

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
